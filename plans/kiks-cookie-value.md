# kiks cookie value codec

kiks already operates on `[]byte`. Cookie structs should own that conversion.

Today `Plain[T]`, `Signed[T]`, `Encrypted[T]`, and `Session[T]` accept any `T`. The jar gob-encodes the concrete value, then:

1. **plain** — base64 of those bytes
2. **signed / encrypted** — gorilla/securecookie over those bytes
3. **session** — gob envelope `{Payload []byte, Flashes []FlashMessage}`, then encrypt that envelope

Gob is an implementation detail leaking into the public type parameter. There is no compile-time contract, schema evolution is opaque, and extra types still tempt `gob.Register`.

## Layers (keep these separate)

| Layer | Owner | Bytes mean |
| --- | --- | --- |
| Payload | app type (`cookies.App`, a theme cookie, …) | the value itself |
| Session envelope | kiks | payload bytes + flashes |
| Transport | kiks + securecookie | signed/encrypted cookie string |

The interface this plan adds is **payload only**. kiks keeps the envelope and the cookie string.

## Constraint

Both methods live on `*T`. `Get`/`Set` still use `T` by value.

```go
// Cookie is the payload stored inside a named cookie.
// MarshalCookie returns raw payload bytes. kiks signs, encrypts, or
// wraps those bytes afterwards — never return a Set-Cookie string.
type Cookie interface {
	MarshalCookie() ([]byte, error)
	UnmarshalCookie([]byte) error
}

func Session[T any, PT interface {
	*T
	Cookie
}](name string, opts ...Option) Definition
```

Same constraint on `Plain`, `Signed`, and `Encrypted`.

Call sites stay the same — Go infers `PT`:

```go
kiks.Session[cookies.App]("app", kiks.HTTPOnly(), kiks.Secure(secure), kiks.MaxAge(maxAge))

kiks.Set(ctx, cookies.App{UserID: user.ID, IsAuthenticated: true})
app := kiks.Get[cookies.App](ctx)
```

Empty payload (`len == 0`) decodes to the zero `T`. Corrupt payloads keep the existing recover-and-dirty behavior.

## Before / after encode path

Today (`typedDef[T]` gob-encodes any `T`):

```go
func (definition *typedDef[T]) encodePayload(value any) ([]byte, error) {
	typed, ok := value.(T)
	// ...
	var buffer bytes.Buffer
	if err := gob.NewEncoder(&buffer).Encode(typed); err != nil {
		return nil, err
	}
	return buffer.Bytes(), nil
}
```

After (payload owns the bytes; jar only transports them):

```go
func (definition *typedDef[T, PT]) encodePayload(value any) ([]byte, error) {
	typed, ok := value.(T)
	if !ok && value != nil {
		return nil, fmt.Errorf("kiks: value type %T does not match cookie %s", value, definition.name)
	}
	var ptr PT = &typed
	return ptr.MarshalCookie()
}

func (definition *typedDef[T, PT]) decodePayload(payload []byte) (any, error) {
	var value T
	var ptr PT = &value
	if len(payload) == 0 {
		return value, nil
	}
	if err := ptr.UnmarshalCookie(payload); err != nil {
		return value, err
	}
	return value, nil
}
```

Session envelope stays private to kiks (still gob of `{Payload, Flashes}`), then encrypted:

```go
type sessionBlob struct {
	Payload []byte
	Flashes []FlashMessage
}

// persist path, simplified:
payload, _ := definition.encodePayload(value) // App.MarshalCookie()
encoded, _ := encodeSessionBlobBytes(sessionBlob{Payload: payload, Flashes: outgoingFlashes})
raw, _ := jar.encrypted.Encode(name, encoded)
http.SetCookie(w, newCookie(name, raw, opts))
```

## Generated `cookies.App`

Full generated shape:

```go
package cookies

import (
	"encoding/json"

	"github.com/mbvlabs/andurel/pkg/kiks"
)

type App struct {
	UserID          string
	IsAdmin         bool
	IsAuthenticated bool
}

func (a *App) MarshalCookie() ([]byte, error) {
	return json.Marshal(a)
}

func (a *App) UnmarshalCookie(data []byte) error {
	if len(data) == 0 {
		*a = App{}
		return nil
	}
	return json.Unmarshal(data, a)
}

func Definitions(name string, secure bool, maxAge int) []kiks.Definition {
	return []kiks.Definition{
		kiks.Session[App](
			name,
			kiks.HTTPOnly(),
			kiks.Secure(secure),
			kiks.MaxAge(maxAge),
		),
	}
}
```

JSON lets fields appear or disappear without gob type ids. Session cookies stay small.

## Extra named cookie (not generated by default)

Primitives need a named type plus the two methods — that is intentional:

```go
type Theme string

func (t *Theme) MarshalCookie() ([]byte, error) {
	return []byte(*t), nil
}

func (t *Theme) UnmarshalCookie(data []byte) error {
	*t = Theme(data)
	return nil
}

// Definitions append:
kiks.Encrypted[Theme]("theme", kiks.HTTPOnly()),
```

kiks tests use the same pattern on `testApp` (JSON like `App`).

## What we are not doing

- **Not** `encoding.BinaryMarshaler`. Too easy to satisfy accidentally, and the name does not say “this becomes a cookie payload.”
- **Not** gob inside generated `App`. Gob can stay as kiks’s private session-envelope codec.
- **Not** SQL / `SessionStore`. Cookie-only jar; payload interface does not reopen that.
- **Not** a toast/UI contract. Flashes stay `[]FlashMessage` on the envelope, not on `App`.

## Open choice

JSON for generated `App` is the default. If cookie size ever matters, swap the method bodies (msgpack, a versioned binary prefix) without changing kiks. The jar never inspects payload bytes.
