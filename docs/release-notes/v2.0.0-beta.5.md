# v2.0.0-beta.5

Fixes from the beta.4 site port: verification of payload packages with tests,
plain Go timestamps at the domain boundary, `Pattern()` route registration in
examples, heterogeneous JSON payload maps, and disclosed query-sync manifest
changes. No `pkg/*` module changes.

## Scaffold

- The generated `User` and `Token` entities use plain Go timestamps:
  `time.Time` for `NOT NULL` columns and `*time.Time` for nullable ones (nil is
  SQL `NULL`). pgx scans `timestamptz` into them directly, so both keep
  automatic mapping and `entity-columns` checks every field. `pgtype` stays
  inside `domains/`: an unexported helper converts a nullable time into the
  generated query params. Services, seeds, and handler tests no longer import
  `pgtype`.
- `UpdateUserData` updates the nullable `email_validated_at` explicitly: a
  non-nil `EmailValidatedAt` sets it, nil keeps it, and
  `ClearEmailValidatedAt` sets `NULL` and takes precedence.
- `Token.Validate` rejects a zero `expires_at`; the former `pgtype` field hid an
  unset expiry from the required check.
- The generated domain tests cover timestamp set, preserve, clear, and
  read-back, including the list path, against a real PostgreSQL database. The
  token domain gains tests for the timestamp round trip and expiry.
- The README documents `andurel --version` and `inspect project --json`, and
  warns that development seeds create demo accounts with known passwords.

## CLI

- `verify` no longer reports `payloads-import` for the synthetic test main Go
  builds for a package with tests. Real application and generated sources are
  still checked. Scoped verification reports the package scope it checked.
- `patterns show domain` renders plain Go timestamps. A `pgtype.Timestamptz` row
  field becomes `time.Time` when `Create<Entity>Params` takes `time.Time`, and
  `*time.Time` otherwise; the rendered entity says when nullability could not be
  read from the params. A nullable-time helper is emitted only when needed. A
  query file that fails to parse no longer aborts the command.
- `sync payloads` maps `map[string]any` to `Record<string, unknown>`, nullable
  like other nil-able Go values, instead of failing with an unmapped type.
- `sync queries` discloses that generation may change the shared `go.mod` and
  `go.sum`, and `--dry-run` previews query and manifest changes in a temporary
  copy. The preview is not a lock; coordinate with other writers.
- Handler, middleware, and route patterns register routes with `Pattern()`,
  which preserves `routing.Exact()`, and build URLs with `Path()`.
- Domain-pattern and layer-placement guidance describe plain Go entity
  timestamps, and document nested DTO mapping, recursive nullability, omission
  and raw JSON, and typed-nil `FromStruct` values for payloads.

## Existing applications

Application-owned code is not rewritten automatically, and this release adds no
manual upgrade actions. Existing `domains/user.go` and `domains/token.go` keep
their `pgtype.Timestamptz` fields and continue to work. To adopt the new shape,
copy it from a fresh `andurel new`: change the entity fields to `time.Time` /
`*time.Time`, build nullable params with a helper, replace
`pgtype.Timestamptz{Time: ..., Valid: true}` in callers with plain times, and
add `ClearEmailValidatedAt` if you need to reset verification.

`inspect domains` reports a type-difference note for each `timestamptz` column
scanned into a plain time. It is informational; `columns_ok` stays true.

## Package versions

No standalone module changes. The `pkg/*` versions published with beta.4
remain current.
