# Andurel 2.0 — Second Release Candidate

> **Release candidate.** `v2.0.0-rc.2` is not stable 2.0. Use it for new
> projects and evaluation, not as a production v1 migration promise. Breaking
> changes are still possible.

## Changes since rc.1

- `andurel run` standardizes development on Go at port 8080 and Vite at port
  5173; the port 3000 proxy is retired. Vite handles HMR, while full reloads
  wait for the restarted Go server to respond at `/api/health`. Site readiness,
  including the database and required SSR dependency, remains `/api/ready`.
- The scaffold uses a single root `css/base.css` pipeline. Named routes come
  from Go, and `routes.ViteBuild` remains Vite-only: assets are served under
  `/assets/dist/` with content hashes as before.
- Plain `andurel verify` checks asset setup by default, with no per-rule flags
  needed. Vite configuration belongs to the application and must match the new
  runner: verification diagnoses mismatches but does not rewrite it. When
  upgrading, compare with a fresh scaffold using the same adapter.
- Verification reports `PASS WITH SKIPS` and a partial summary when Go test
  suites, tests, or subtests are skipped. The Go test step's additive
  `execution_complete` boolean is true only when the test command succeeds
  without reported skips, false for failures or skips, and omitted when tests
  are not run. Existing default `status: ok` values remain compatible.
  The optional global `--require-test-execution` implies tests and fails when
  a test-bearing package reports no test events, such as `TestMain` exiting
  before `m.Run`. Individual skips, cached results, and packages without test
  files remain allowed.
- Go 1.27.4 and patched OpenTelemetry, compression, and crypto dependencies
  address security issues through standalone-module patch releases. No Andurel
  runtime API changes were needed for these dependency updates.

## Install

```bash
go install github.com/mbvlabs/andurel/v2@v2.0.0-rc.2
andurel --version
```

## Validation

The release requires a successful post-merge readiness run on its exact
`master` commit, including published-dependency goldens and upgrade E2E.
Real Vite/Chromium smoke checks also exercised the runner with a mock Go app.
Local Docker was inaccessible, so those local checks are not a database-backed
application qualification claim.
