# v2.0.0-beta.2

Fixes found while building a real site on `v2.0.0-beta.1`. Agents ported
andurel.com to the beta and logged every point of friction. This release fixes
the bugs they hit, fills the gaps in production builds and SSR, and corrects
the CLI help, skill and patterns where they disagreed with the scaffold.

## Highlights

- **Auth email works out of the box.** The default sender was
  `noreply@localhost:8080`, which `pkg/email` rejects, so every queued
  verification and password-reset email was cancelled silently. The default
  now drops the port, an invalid sender fails at startup, and email workers log
  failed jobs.
- **Exact routes and a themed 404.** `routing.Exact()` and `Pattern()` let the
  home route register as `GET /{$}` instead of catching every path, and
  unmatched requests reach the app's `ErrorHandler` as `anduin.ErrNotFound`, so
  the scaffold renders `Errors/NotFound` instead of plain text.
- **`andurel build` builds every process.** It compiles `cmd/app`, `cmd/queue`,
  `cmd/migrate` and `cmd/ssr` into `dist/`, prints an artifact summary, and
  supports `--only` and `--json`. `andurel patterns show deploy` documents
  start order, environment and health checks.
- **SSR that works in production and in dev.** The production SSR bundle is
  self-contained, so `cmd/ssr` runs without `node_modules`. Dev SSR through
  Vite is unchanged. Error pages can opt into SSR, and an unmapped 5xx renders
  the themed `Errors/InternalError` page.

## CLI

- `andurel verify` gains a `frontend` stage that runs the project's
  `typecheck` script (skip it with `--no-frontend`), accepts Go package
  patterns to scope gofmt, fix, vet and layers, and checks `email/*_templ.go`
  against the email compiler.
- New `andurel inspect config [--json]` lists every environment key the
  `config` package reads, with its default and source line.
- `andurel sync payloads` follows named structs across packages in the module.
  `andurel sync email --json` lists the files it wrote.
- `andurel inspect routes` reports `pattern`, `exact` and `host` on every
  route. `andurel inspect jobs` tells jobs from workers by their code.
- `andurel doctor` reads `ENVIRONMENT` and requires the SSR bundle in
  production.
- `andurel skill show <reference>` prints a skill reference.
- `--jq` supports array indexes such as `.routes[0].name`.
- Help text and `commands --json` metadata are corrected throughout,
  including the `andurel.toml` and `andurel.lock` split.

## Scaffold (new applications)

- Flash messages work end to end: `kiks` is the Inertia flash provider, every
  layout renders flashes, and sign-out flashes a message. Sign-out also accepts
  `POST` for a form without JavaScript.
- Gzip compression through `anduin.Compress`, behind `HTTP_COMPRESS`.
- `SITE_NAME` sets a display name, shared with the frontend as `siteName`.
- `.env.example` lists every key the config reads, grouped by file.
- `package.json` has a `typecheck` script and `engines.node >= 22`.
- `cmd/queue` loads only the worker configuration.
- `EMAIL_PROVIDER=log` allows a production-like local run without SMTP.
- Routes use `routing.TypeScriptRoute()` (`InertiaRoute()` is a deprecated
  alias).

## Skill and patterns

- New patterns: `deploy`, `page`, `middleware`, `test-middleware`.
- The `composition` and `route` patterns match the scaffold and the generated
  `routes.ts`.
- The HTTP reference covers exact routes, CSRF, Inertia form behaviour for
  tests and curl, SSR and `RootData`.

## Package versions

These modules are published with this release:

| Module | Version | Change |
| --- | --- | --- |
| `pkg/anduin` | `v0.5.0` | `ErrNotFound`, `Blob`, `ServeContent`, `Compress`, `SitemapURL.LastMod`, `anduintest.WithErrorHandler` |
| `pkg/email` | `v0.6.0` | `Log` sender |
| `pkg/inertia` | `v0.11.0` | `ErrorMapping.SSR`, `NewErrorHandler`, embedded SSR bundle fallback |
| `pkg/kiks` | `v0.6.0` | **Breaking:** `AddFlash` returns an error, `Flashes` returns `any`. Flashes survive `Destroy`. |
| `pkg/routing` | `v0.6.0` | **Breaking:** route interfaces gain `Pattern()`. `Exact()`, `TypeScriptRoute()` |

The other modules are unchanged from `v2.0.0-beta.1`.

## Known issues

- `GO-2026-5932` (`crypto/openpgp` in `golang.org/x/crypto`) has no fixed
  version. `pkg/auth` and `pkg/storage` require the module but never call the
  affected package, so `govulncheck` does not report it as reachable.

## Upgrade notes

Upgrading from `v2.0.0-beta.1` reports three manual actions:

| ID | Change |
| --- | --- |
| `email-sender-v2.0.0-beta.2` | Strip the port from the default sender in `config/email.go` and validate it. |
| `vite-ssr-bundle-v2.0.0-beta.2` | Inertia projects: bundle SSR dependencies into the production build only. |
| `root-title-ssr-v2.0.0-beta.2` | Inertia projects: render the fallback `<title>` only for client-rendered pages. |

Run:

```text
andurel upgrade
go mod tidy
go vet ./...
```

then apply each manual action from the report. The other scaffold changes are
defaults for new applications; copy them from a fresh `andurel new` if you
want them. The breaking `kiks` and `routing` changes do not affect a beta.1
scaffold, which does not call `AddFlash` or implement the route interfaces.

Upgrading from `v2.0.0-alpha.4` or `v2.0.0-alpha.5` also reports their earlier
manual actions; see `docs/generated-files-and-upgrades.md`.
