# v2.0.0-beta.3

A second round of fixes from porting andurel.com to the V2 beta. This release
fixes cross-host asset caching, narrows the scaffold's CORS trust to explicit
origins, adds a single host resolver, and makes a method mismatch render the
themed not-found page. It also closes the `FromStruct` gaps in
`andurel sync payloads` and reports skipped tests from `andurel verify`.

## Highlights

- **Cross-host assets cache correctly.** `StaticFS` and `ServeContent` now merge
  `Vary` instead of replacing it, so CORS's `Vary: Origin` survives next to
  `Accept-Encoding`, and a conditional `304 Not Modified` carries the same
  headers as the `200`. A CDN or browser cache can no longer store an asset
  response under one origin and reuse it for another.
- **CORS no longer trusts host origins.** The scaffold's global policy allows
  only `CORS_ALLOWED_ORIGINS`. Host origins remain in CSRF (same-site form posts
  between app hosts are deliberate), but a sibling host can no longer read
  authenticated API responses in a browser. Vite build files get their own
  wildcard, uncredentialed policy, and safe asset requests no longer receive
  the CSRF cookie. **Security-relevant for apps with more than one configured
  host.**
- **Host-aware policy from one resolver.** `anduin.RequestHost(ctx)` reports the
  `routing.HostName` the dispatcher resolved, before global middleware runs.
  `routing.Hosts.Resolve` is the same resolution, now case-insensitive, with
  alias and bare-hostname/port handling. The scaffold ships an unwired
  `middleware.DenyFraming` example for host-scoped framing headers.
- **405 goes through the `ErrorHandler`.** A `ServeMux` method mismatch now
  reaches the app as `anduin.ErrMethodNotAllowed` with the `Allow` header
  preserved, and the scaffold renders `Errors/NotFound` with status 405 instead
  of a plain-text response. **Behaviour change** for handlers that branch on the
  previous response.
- **`PageBuilder.URL`.** A POST handler that renders a success page can set the
  page object's `url` to a GET-able route in the JSON and full-document/SSR
  responses.
- **Better CLI evidence.** `andurel sync payloads` follows named structs through
  function and closure parameters, including pointers, and gains `--strict`.
  `andurel verify` reports `skipped_tests` and unresolved payload roots as
  `warnings` without failing the run.

## HTTP and routing

- `anduin.AddVary(header, tokens...)` appends a token only when the header does
  not already list it, case-insensitively across comma-separated values.
  `Compress`, `StaticFS` and `ServeContent` use it; there is no private copy
  left.
- `StaticFS` and `ServeContent` keep CORS's `Vary: Origin`, and a conditional
  `304` now carries `Vary: Accept-Encoding`. Compressed and uncompressed
  responses agree.
- `anduin.RequestHost(ctx)` returns the resolved `routing.HostName` for
  middleware, handlers and the root document. Unknown authorities report
  `routing.HostPrimary`; a configured host with no registered routes is still
  reported while dispatch falls back to the primary mux.
- `anduin.ErrMethodNotAllowed` is passed to the `ErrorHandler` when the path
  matches but the method does not. `StatusCode` maps it to 405, the `Allow`
  header set by `http.ServeMux` survives, and a router without an
  `ErrorHandler` still answers 405.
- `anduintest.WithHosts` installs a host registry on the test router, and a
  `Header{Name: "Host"}` request option sets `req.Host` so tests can target a
  named virtual host.
- Router host matching is case-insensitive and shares
  `routing.Hosts.Resolve` instead of a private index.

## Inertia

- `PageBuilder.URL` overrides the page object's `url` in the JSON
  (`X-Inertia`), full-document and SSR responses alike.
- The renderer reuses `anduin.AddVary`; the anonymous `crossorigin` mode on
  Vite tags is documented and locked by a test, matching the scaffold's
  uncredentialed asset policy.

## CLI

- `andurel sync payloads` seeds its scanner with function and closure
  parameters, including pointer and named types, so `FromStruct(param)` and
  `FromStruct(*props)` resolve. Rebound local names with different types stay
  ambiguous rather than guessing.
- `andurel sync payloads --strict` writes `payloads.ts` and then exits
  non-zero on any unresolved `FromStruct` root, listing each `file:line`. Human
  output names the same locations with a hint to pass a named composite
  literal or a typed variable.
- `andurel verify --with-tests` collects `t.Skip` events into `skipped_tests`
  with their reason. A skipped test does not fail the step, mirroring
  `skipped_packages`.
- `andurel verify` reports unresolved `FromStruct` roots as generated-step
  `warnings` without failing the run.
- Help text, `commands --json` metadata and the CLI catalog document the new
  payload and verify output, including that `--strict` writes the file before
  failing.

## Scaffold (new applications)

- Global CORS trusts only `CORS_ALLOWED_ORIGINS`; the Vite asset route answers
  with wildcard, uncredentialed CORS and the global middleware skips it.
- Safe requests under the Vite asset prefix skip CSRF, so `/assets/dist/*`
  responses no longer set `_csrf`. Unsafe asset requests stay protected.
- `handlers.MapError` maps `anduin.ErrMethodNotAllowed` to
  `Errors/NotFound` with status 405.
- `middleware.DenyFraming(hosts ...routing.HostName)` branches on
  `anduin.RequestHost` and sets `X-Frame-Options: DENY` and
  `Content-Security-Policy: frame-ancestors 'none'` before the handler runs.
  The CSP is appended as a separate policy so existing restrictions survive.
  It ships unwired; the readme shows the one-line install for an admin host.
- The root template renders with the request context, so it can read
  `anduin.RequestHost(ctx)` for document-level differences.
- Runtime tests cover credentials-free asset CORS, the CSRF skip, and the
  themed 405 for both Inertia and document requests.

## Documentation and skill

- The readme documents the CORS split, `RequestHost`, `Hosts.Resolve`,
  `DenyFraming`, host-aware root templates, cross-host links (plain `<a>`, not
  Inertia `<Link>`), `PageBuilder.URL`, and 405 rendering.
- The testing section documents testcontainers' shared Ryuk session: under
  parallel packages one package can reap a sibling's container, so use
  `go test -p 1 ./...` or `TESTCONTAINERS_RYUK_DISABLED=true`.
- The testing section documents `skipped_tests`, `warnings`, and skipping
  tests that need `assets/dist` when the frontend has not been built.
- The `http-and-routing` skill reference covers `AddVary`, `RequestHost`,
  `Hosts.Resolve`, `ErrMethodNotAllowed`, the CORS/CSRF composition, and the
  `anduintest` host options.

## Security dependency update

- `pkg/email v0.6.1` updates `golang.org/x/net` to v0.62.0, fixing
  **GO-2026-6860**, a quadratic-time HTML text-node coalescing vulnerability
  reachable through `email.HTMLToText`. New and upgraded applications pin this
  corrected email version.

## Package versions

These modules are published with this release:

| Module | Version | Change |
| --- | --- | --- |
| `pkg/anduin` | `v0.6.1` | `AddVary`, `RequestHost`, `ErrMethodNotAllowed`, `anduintest.WithHosts`; static `Vary` merge and 405 routing fixes; corrected routing dependency |
| `pkg/inertia` | `v0.12.1` | `PageBuilder.URL`; corrected anduin dependency |
| `pkg/email` | `v0.6.1` | Update `x/net` to fix GO-2026-6860 in `HTMLToText` |
| `pkg/routing` | `v0.7.0` | `Hosts.Resolve`; case-insensitive host matching |

The other modules are unchanged from `v2.0.0-beta.2`.

Use these patch versions rather than `anduin v0.6.0` and `inertia v0.12.0`:
those initial tags declared dependencies older than the APIs they use. The
patches correct the minimum requirements so standalone consumers compile
without adding compensating dependency pins.

## Known issues

- `GO-2026-5932` (`crypto/openpgp` in `golang.org/x/crypto`) has no fixed
  version. `pkg/auth` and `pkg/storage` require the module but never call the
  affected package, so `govulncheck` does not report it as reachable.

## Upgrade notes

Upgrading from `v2.0.0-beta.2` reports four manual actions:

| ID | Change |
| --- | --- |
| `cors-host-origins-v2.0.0-beta.3` | Trust only `CORS_ALLOWED_ORIGINS`, skip the asset prefix, and serve Vite assets with wildcard, uncredentialed CORS. Security-relevant for multi-host apps. |
| `csrf-asset-skip-v2.0.0-beta.3` | Skip CSRF cookie issuance for safe asset requests. |
| `method-not-allowed-page-v2.0.0-beta.3` | Map `anduin.ErrMethodNotAllowed` to the themed `Errors/NotFound` page. |
| `request-host-middleware-v2.0.0-beta.3` | Advisory: replace hand-written host matching with `anduin.RequestHost` and use `middleware.DenyFraming`. |

Run:

```text
andurel upgrade
go mod tidy
go vet ./...
```

then apply each manual action from the report. The CORS and CSRF actions touch
`internal/runtime` and `handlers/assets.go`; keep `cfg.App.Origins()` in the
CSRF trusted origins. The 405 mapping is a behaviour change: handlers that
previously received a plain-text method mismatch now render the themed page.
The other scaffold changes are defaults for new applications; copy them from a
fresh `andurel new` if you want them.

Upgrading from `v2.0.0-beta.1`, `v2.0.0-alpha.5` or `v2.0.0-alpha.4` also
reports their earlier manual actions; see `docs/generated-files-and-upgrades.md`.
